# Формат: «сценарий выживания» (вертикальные Shorts)

Разбор эталонного ролика (9:16, 1:46, 30 fps) — «Если в 3:17 ночи ваш телефон…» → «Часть 2: Не открывай».

## Структура (≈ 100 с)

| Время | Блок | Что в эталоне |
|---|---|---|
| 0–8 с | **Хук** | Экстренное оповещение на телефоне: «Не выходите. Не открывайте окна. **Не смотрите на небо.**» Время 03:17. |
| 8–15 с | **Ставка** | «У вас есть всего несколько часов до утра». Дом в разрезе: 7 этаж, заряд 14%, вода, дверь. |
| 15–55 с | **Правила** | Чек-лист «Первые 7 минут»: шторы и свет (ошибка №1 — окно видно за км), заряд телефона, ванна воды 180 л, 2 замка + цепочка. «9 из 10 — не успели». |
| 55–85 с | **Эскалация** | Соседи выходят во двор, хлопают двери, кто-то смеётся. 10 человек стоят неподвижно и смотрят вверх. |
| 85–100 с | **Пик** | 5:20 — последнее сообщение от мамы «Никому не открывай». 5:31 — три тихих стука в дверь, свет под дверью. |
| 100–106 с | **Клиффхэнгер** | Глитч «ЧАСТЬ 2 — НЕ ОТКРЫВАЙ» + «А ты бы открыл? Пиши в комментариях» + «Подпишись». |

Принципы сценария: второе лицо («вы»), короткие фразы, конкретные числа (3:17, 14%, 180 л, 9 из 10), каждое правило — действие + почему, жуть показывается, а не объясняется. Ни разу не говорить, что именно в небе.

## Визуальный стиль

- **Фон:** почти чёрный (#07080c), ночной город из точек-окон внизу кадра, лёгкое зерно/виньетка.
- **HUD сверху:** плашка `ДЕНЬ 1 — 03:18`, моноширинный шрифт, жёлтый (#f5c542) на тёмном. Время растёт по ходу ролика.
- **Субтитры:** по центру нижней трети, жирный гротеск капсом (Inter/Manrope Black), 2 строки максимум, пословное появление. Акценты: жёлтый — числа и ключевое, красный (#ff3b3b) — угроза, серый — второстепенное.
- **Инфо-плашки:** неоновые рамки с иконкой и подстрочником (`ЗАРЯД 14% / телефон`, `ОШИБКА №1: ОКНО / видно за 1 км`). Цвет по смыслу: голубой — инфо, зелёный — безопасно, красный — опасность.
- **Движение:** мягкие наезды/zoom 1.0→1.08, плашки выезжают с пружиной, линии-выноски дорисовываются, счётчики крутятся (20% → 28% → 36%, 0 → 97 → 180 л).
- **Звук:** спокойная мужская озвучка без пауз, низкий эмбиент-дрон, импакты на смене сцен, тишина перед стуком.

## Библиотека сцен

| Тип | Описание |
|---|---|
| `alert-phone` | Телефон с красным экстренным оповещением, строки появляются по одной |
| `building-xray` | Панельный дом, окна-точки, выноски к «вашей» квартире |
| `window-grid` | Сетка окон с силуэтами, «ваше» окно гаснет → «вас не видно» |
| `battery` | Батарея с растущим процентом + теги устройств |
| `tank-fill` | Ёмкость с заполнением и счётчиком литров |
| `checklist` | Чек-лист «Первые N минут», галочки по одной |
| `dots-stat` | Ряд из 10 фигур, «9 из 10 — не успели», «вы» подсвечены |
| `stairwell` | Схема подъезда по этажам, красные точки-соседи движутся вниз |
| `crowd-silhouettes` | Тёмный двор, силуэты смотрят вверх, плашка-таймер |
| `chat` | Переписка в мессенджере, «был(а) в сети в 03:15» |
| `door` | Входная дверь, глазок, цепочка, счётчик `СТУК: 3`, свет из-под двери |

| `screens-sync` | ТВ, телефон, колонка загораются по очереди с одной фразой |
| `voice-wave` | Колонка с кольцом + эквалайзер + прогресс «образец голоса» |

| `smart-lock` | Дверь с кнопочным замком: батарейки выпадают, засов, цепочка |
| `yard-map` | Двор сверху, фургон едет вдоль подъездов, таймер стоянки |
| `floorplan-vacuum` | План квартиры, маршрут пылесоса прорисовывается, «вы» этажом ниже |

## Техника

Рабочий конвейер (эталон — `01-vosstanie-mashin/`, копировать `tools/` и `scenes/` в новый эпизод):
1. `voiceover.txt` — текст озвучки, числа словами → vidIQ `voiceover_generate` → `audio/voice.wav` (`atempo≈1.07`).
2. `tools/align.py` — пословные таймкоды по паузам (ASR в облачной сессии недоступен).
3. `scenes/index.html` — все сцены, `renderAt(t)` детерминирован по времени; сцены и ключевые моменты привязаны к словам озвучки (`scene('фраза', 'ЧЧ:ММ', {ключ:'слово'}, build, update)`).
4. `tools/render.mjs` — Playwright → ffmpeg, 4 воркера; `preview` для проверочных кадров.
5. `tools/mix.py` — голос + музыка с даккингом + синтезированные SFX, громкость −14 LUFS.


- 1080×1920, 30 fps, H.264 + AAC, ≤ 2 мин. Safe-зона: 150 px сверху, 400 px снизу (интерфейс Shorts/TikTok).
- Сцены — HTML/CSS/JS (скиллы `hyperframes:*`), одна сцена = один компонент с параметрами.
- Пословные субтитры строятся из таймкодов озвучки (`audio/words.json`).
- Проверка: `ffmpeg -i render/final.mp4 -vf "fps=1/4,scale=360:-1,tile=6x3" render/sheet.png`.
