# Тихий подъезд (бывший @kruzhochky)

## Оформление канала
- **Название:** Тихий подъезд
- **Аватар:** `avatar.png` (800×800)
- **Шапка:** `banner.png` (2560×1440, текст в безопасной зоне 1546×423)
- **Описание канала:**

> Страшные истории из самых обычных домов. Чат подъезда, лифт, записки под дверью: всё, что происходит, пока вы спите.
> Новые истории каждый день.

- **Хэштеги по умолчанию:** #тихийподъезд #страшныеистории #мистика #shorts

## Где что менять в YouTube
YouTube Studio → **Настройка канала**:
- **Брендинг:** аватар и шапка.
- **Основные сведения:** название, описание, псевдоним. Псевдоним можно попробовать сменить на `@tihiypodezd`.

## Расписание
3 ролика в день: **12:00, 16:00, 20:00** (МСК). Одна тема в день: части 1, 2 и финал.

## Как делаются ролики
1. Сценарий: `video/stories/tp-XXX-*.json`.
2. Сборка: `python3 video/make.py video/stories/tp-XXX-*.json`.
3. Готовый файл: `video/out/tp-XXX-*.mp4`. Название и описание для публикации берутся из полей `title` и `description` в JSON.
