# Студия сайтов для малого бизнеса

Рабочий репозиторий: портфолио, демо-сайты, клиентские проекты и материалы для продаж.

## Структура

```
index.html            — страница портфолио (наша витрина)
demos/                — демо-сайты для портфолио
clients/<компания>/   — сайты конкретных клиентов
sales/                — шаблоны сообщений, бриф, договор, прайс
leads.csv             — список потенциальных клиентов и статус работы с ними
```

## Конвейер

| Этап | Кто | Что происходит |
|---|---|---|
| 1. Поиск | Claude + вы | Выбираем нишу и город, собираем 20 компаний без сайта или со слабым сайтом в `leads.csv` |
| 2. Черновик | Claude | Делает демо-сайт под конкретную компанию в `clients/<имя>/` |
| 3. Контакт | вы | Отправляете сообщение по шаблону из `sales/outreach.md` со ссылкой на черновик |
| 4. Переговоры | Claude готовит ответы, вы отправляете | Бриф (`sales/brief.md`), цена, предоплата 50% |
| 5. Сборка | Claude | Доработка сайта по брифу, 2 круга правок |
| 6. Запуск | Claude + вы | Домен, хостинг, Метрика, остаток оплаты, чек в «Мой налог» |
| 7. Поддержка | Claude | Подписка 3 000 ₽/мес на правки |

## Статусы в leads.csv

`new` → `draft_ready` → `contacted` → `replied` → `brief` → `prepaid` → `done` / `lost`
